#### NPM-пакет для канвэртацыі беларускай артаграфіі. Рунхавік вэб-праграмы тарашкевізатара

### Content

Пакет канвэртуе акадэмічны правапіс у клясычны. Галоўная функцыя — `tarask`, ё
таксама пайплайны `alphabetic` і экспэрымэнтальны `phonetic`, `splitIntoChunks`
для чанкаў гатовых да воркераў, і кляса `TaraskConfig` з опцыямі альфабэту
(кірыліца, лацінка, арабскі), замены і на j, варыяцыяў, абалонак і літары г.

Пастаўляецца ў 5 відах: npm-бібліятэка з тыпамі, CDN-бандл з глябальнай
зьменнай, што працуе сынхронна бяз ініцыялізацыі, CLI `tarask` з гатовымі
бінарнікамі, што цягнуць шматгігабайтныя ўводы паралельна, Rust бібліятэка, і
JSON-слоўнікі ў GitHub-рэлізах.

```sh
npm install taraskevizer
tarask --latin 'планета'
tarask < ./cyr-text.txt > ./lat-text.txt
```

### History

Празь некаторы час, нехта папрасіў мяне ў іш'ю на GitHub перанесьці лёгіку
канвэртацыі да асобнага npm-пакету. І я перанёс яго разам з генэрацыяй json'аў у
іншы рэпазыторый. Для білдынгу я выбраў tsup, гэта просты білдэр, каторы
дазваляе ўжываць esbuild-плагіны. Стварэньне плагіну для генэрацыі json'аў было
лягчэйшае з esbuild, ніж з Webpack.

Потым, я зрабіў CI/CD з GitHub Actions. Воркфлоў будуе праект і публікуе яго як
нпм-пакет, пасьля пасьпяховай публікацыі яно трыгерыць воркфлоў у рэпазыторыі
вэб-праграмы, каторае робіць білд і публікуе на GitHub Pages.

Пасьля я замяніў бандлінг на трансьпіляцыю і прыбраў tsup з залежнасьцяў.
Увосень 2026 году я перанёс ядро канвэртацыі на Rust з кампіляцыяй у WASM,
канвэртацыя ў браўзэры стала ў 3-4 разы хутчэй, і дадаў гатовыя бінарнікі
`tarask` да кожнага рэлізу.
